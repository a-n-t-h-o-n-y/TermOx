# Documentation

Read these in order for a first application:

1. [Getting started](getting_started.md) — build and run a small app.
2. [Core concepts](core-concepts.md) — ownership, connections, updates, and timers.
3. [Layout](layout.md) — arrange widgets, size them, and add scrolling.

Then use the guides you need:

- [Widgets](widgets.md) — choose a control and see how to use it.
- [Appearance](appearance.md) — themes, colors, styling, and motion.
- [Recipes](recipes.md) — forms, background work, file selection, dialogs, commands, and tables.
- [Custom widgets](custom-widgets.md) — input, painting, and headless testing.

The [API reference](https://a-n-t-h-o-n-y.github.io/TermOx/) documents individual
methods, options, and signals. [Examples](../examples/README.md) contains runnable
apps and build instructions.

For library development, see [Contributing](contributing.md).
